# Security policy

## Reporting a vulnerability

**Do not open public issues** for security vulnerabilities. Use GitHub's
private reporting channel:

https://github.com/emirkanacar/sms_consent_kit/security/advisories/new

You will get a response within 7 days of the report.

## Supported versions

Before `1.0.0`, only the latest published version is supported.
